Como surgiu a Microsoft?

A Microsoft foi fundada em 4 de abril de 1975 por Bill Gates e Paul Allen. Os dois eram apaixonados por computadores e acreditavam que eles poderiam se tornar importantes no futuro.

A empresa começou desenvolvendo softwares para computadores pessoais. Seu primeiro grande projeto foi uma versão da linguagem de programação BASIC para o computador Altair 8800.

O começo da Microsoft

📅 1975

Bill Gates e Paul Allen fundam a Microsoft, inicialmente chamada de "Micro-Soft".

💻 1980

A Microsoft fecha um acordo com a IBM para fornecer um sistema operacional para seus computadores.

🪟 1985

É lançado o Windows 1.0, o primeiro sistema operacional da Microsoft com uma interface gráfica.

Principais momentos

1975 — Fundação

Bill Gates e Paul Allen criam a Microsoft.

1981 — MS-DOS

O sistema operacional MS-DOS começa a ganhar espaço nos computadores da IBM.

1985 — Windows 1.0

A Microsoft lança a primeira versão do Windows.

1995 — Windows 95

O Windows 95 se torna um grande sucesso e ajuda a popularizar os computadores pessoais.

2001 — Windows XP

O Windows XP é lançado e se torna uma das versões mais conhecidas do sistema.

2021 — Windows 11

A Microsoft lança o Windows 11, trazendo uma interface mais moderna.

Produtos e serviços

🪟 Windows

Sistema operacional utilizado em milhões de computadores.

📄 Microsoft 365

Conjunto de aplicativos como Word, Excel e PowerPoint.

🎮 Xbox

Marca de consoles e serviços de videogames da Microsoft.

☁️ Azure

Plataforma de computação em nuvem da Microsoft.

Conclusão

A Microsoft começou em 1975 com o objetivo de desenvolver softwares para computadores. Ao longo dos anos, a empresa cresceu e passou a atuar em diversas áreas da tecnologia.

Atualmente, seus produtos estão presentes em computadores, videogames, empresas e serviços de computação em nuvem, tornando a Microsoft uma empresa importante na história da tecnologia.
